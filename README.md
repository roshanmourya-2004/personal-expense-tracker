# Personal Expense Tracker

A lightweight, responsive web application designed to help individuals record income and expenditures, calculate balances in real-time, and analyze spending patterns through interactive visualizations.

## 📌 Academic Information
* **Degree:** T.Y. B.Sc. Computer Science (Semester 5)
* **Project Type:** Mini Project
* **Course:** Requirement Engineering & Implementation Phase

---

## 🚀 Features
* **User Authentication:** Client-side registration, login verification, and active session management.
* **Transaction Management:** Full CRUD operations (Add, View, Filter, and Delete) for Income and Expense records.
* **Automated Calculations:** Instant balance updates using $\text{Balance} = \text{Total Income} - \text{Total Expenses}$.
* **Data Visualizations:** Dynamic Chart.js visualizations (Category Expense Distribution & Income vs Expense Ratio).
* **Monthly Reports:** Filter reports by month with category-wise progress bars.
* **Persistent Storage:** Browser-level data persistence using `localStorage`.

---

## 🛠️ Technology Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **UI Framework:** Bootstrap 5
* **Data Visualization:** Chart.js
* **Icons:** FontAwesome v6
* **Storage Engine:** Web Storage API (`localStorage`)
